# Deskripsi Halaman

Halaman ini merupakan halaman praktikum Pemrograman Web yang dibuat
menggunakan HTML. Halaman menerapkan struktur HTML semantik yang terdiri
dari header, navigation, main, section, article, form, dan footer.
Halaman juga menerapkan penggunaan heading secara hierarkis, atribut alt
pada gambar, serta label yang terhubung dengan input form.

## Cara Menjalankan Melalui Laragon 5

1. Buka aplikasi Laragon 5.
2. Jalankan Web Server/Apache.
3. Pastikan folder `Pemweb-obe` berada di dalam folder `D:\laragon\www\`.
4. Buka browser.
5. Akses halaman melalui:

   `http://localhost/Pemweb-obe/`

Pengujian halaman dilakukan melalui URL localhost dan bukan menggunakan
`file:///`.

## Fitur yang Sudah Selesai

- Struktur HTML semantik.
- Header dan navigation.
- Main dengan minimal tiga section.
- Article.
- Form kontak.
- Footer.
- Hierarki heading menggunakan `h1`, `h2`, dan `h3`.
- Gambar dengan atribut `alt`.
- Label yang terhubung dengan input form.
- Navigasi menggunakan tombol Tab.
- Link dan kontrol form dapat difokuskan dengan urutan yang logis.
