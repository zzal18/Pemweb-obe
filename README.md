## Deskripsi Proyek
Proyek ini merupakan implementasi sederhana untuk memenuhi kebutuhan praktikum Pemrograman Web berbasis OBE. Proyek dibuat menggunakan HTML dan dijalankan menggunakan web server lokal Laragon 5.

## Teknologi yang Digunakan
- HTML
- PHP
- Laragon 5
- Git
- GitHub
- Visual Studio Code

## Cara Menjalankan Proyek
1. Pastikan Laragon 5 sudah terpasang.
2. Jalankan aplikasi Laragon.
3. Aktifkan web server Apache.
4. Simpan folder proyek pada:
   `D:\laragon\www\Pemweb-obe`
5. Buka browser.
6. Akses alamat:
   `http://localhost/Pemweb-obe/`
7. Halaman utama proyek akan ditampilkan melalui file `index.html`.
